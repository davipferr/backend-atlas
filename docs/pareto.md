# The 80/20 Path

The Pareto rule applied to this atlas: the **20% of concepts that explain 80% of what you meet
building, running and debugging real backends**. It is for a developer who already writes APIs
but never looked below the framework. Read the steps in order. Each one builds on the previous
ones, and each link goes straight to the concept in the atlas.
